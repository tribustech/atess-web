**Goal:** Reorganize Proiecte from a flat masonry gallery into a per-project, category-grouped portfolio with per-project detail routes and a scaffolded Romania-map view that filters projects by județ, while keeping the `gallery.json` build pipeline (`npm run gallery:build`) intact.

**Architecture:** `projects.json` becomes the single source of truth for curated per-project records (location, year, category, system, surface, narrative, image set), validated and typed by a new `src/lib/projects.ts` library; `gallery.json` stays as the auto-built image index and is linked to projects via `projectSlug`. The Proiecte index renders projects grouped by category with category filter chips drawn from the shared Servicii taxonomy, each project links to a static detail route `proiecte/[slug]`, and a separate `proiecte/harta` route mounts the copied `RomaniaMAP.svg` with a placeholder county→projects interaction. All photos referenced are placeholders (existing `/images/*.webp` or a single placeholder) until Teo curates real per-project folders.

- [ ] Create `src/lib/projects.ts` with the imports and Zod schema:
  ```ts
  import { z } from "zod";
  import projectsRaw from "@/data/projects.json";
  import systemsRaw from "@/data/systems.json";
  import { PROJECT_CATEGORIES, type ProjectCategory } from "@/lib/gallery";

  const CATEGORY_SLUGS = PROJECT_CATEGORIES.map((c) => c.slug) as [
    ProjectCategory,
    ...ProjectCategory[],
  ];
  const SYSTEM_SLUGS = (systemsRaw as { slug: string }[]).map((s) => s.slug);

  const projectSchema = z.object({
    slug: z.string().min(1),
    title: z.string().min(1),
    locationCity: z.string().min(1),
    locationJudet: z.string().min(1),
    year: z.number().int().gte(2000).lte(2100),
    category: z.enum(CATEGORY_SLUGS),
    systemSlug: z.string().refine((s) => SYSTEM_SLUGS.includes(s), {
      message: "systemSlug must match a slug in systems.json",
    }),
    surfaceM2: z.number().positive(),
    client: z.string().optional(),
    description: z.string().min(1),
    whatWeDid: z.array(z.string().min(1)).min(1),
    heroImage: z.string().min(1),
    images: z.array(z.string().min(1)).min(1),
    featured: z.boolean().optional(),
  });

  export type Project = z.infer<typeof projectSchema>;
  ```
